第 11 節：製作與彩排
  1. 選定足球任務：聲控開球、夜間球場、循線跑位、辨色裁判、避障守門或遙控傳球。
  2. 完成作品最小可展示版本，並記錄至少一次失敗與修正。
  3. 排 90 秒介紹：30 秒情境、40 秒展示、20 秒程式邏輯。
  4. 同組輪流檢查每位成員是否都有工作與發言。
第 12 節：展示賽
  1. 每組完成正式展示與現場操作。
  2. 其他組給一個優點和一個具體建議。
  3. 教師依評量規準給分，並把分數登錄到後台。
  4. 全班討論下一版機器人足球聯盟可加入什麼規則。

永久網址、GitHub Pages 與 Google Sheet

Cloudflare Quick Tunnel 是臨時預覽網址。永久版本建議放到 GitHub Pages，後台用 Google Sheet 搭配 Apps Script Web App。

網域說明：`trycloudflare.com` 臨時網址不是永久網址，電腦或 tunnel 關掉就可能失效。GitHub Pages 會給你 `https://你的帳號.github.io/儲存庫名稱/`，也可以再綁定自己的自訂網域。
Google Apps Script API 設定
尚未測試。完成部署後，請先按「測試連線」，再按「初始化後台」。
GitHub Pages 發布步驟
  1. 在 GitHub 建立新 repository，例如 `mblock-soccer-course`。
  2. 把 `outputs` 裡的網站檔案上傳到 repository 根目錄。
  3. 到 Settings → Pages，Source 選 `Deploy from a branch`。
  4. Branch 選 `main`，資料夾選 `/root`，按 Save。
  5. 等待 GitHub 產生網址，再把網址貼回 Google Sheet 的 Settings。
